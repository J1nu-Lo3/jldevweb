## Installation & lancement

Clone le projet :
git clone https://github.com/ton-username/jldevweb.git
cd jldevweb

Installe les dépendances :
npm install

Lance le serveur de développement :
npm run dev

Build du projet :
npm run build

Preview du build :
npm run preview
